\section{Purpose}
This document lists the nine milestones of the LipScribe implementation, when
each is due, and the criteria used to decide that it is complete. The
milestones come from Section~12 of the \emph{Technical Implementation and
System Development Document} and are tracked on the team's Trello board, where
the Work Breakdown Structure (WBS) breaks each milestone into cards with an
owner, a reviewer and a due date.

The implementation runs for six weeks, from Monday 19~October to
Sunday 29~November 2026. Each week ends with a milestone review on Sunday,
chaired by the project coordinator (Charis Opol), where the completion criteria
are checked and the next week is re-planned.

\section{Review process and fallback plan}
\begin{itemize}
  \item A milestone is complete only when all its criteria are met and the
        reviewer of each card has approved the work. Unfinished cards move to
        the next week with a written reason.
  \item If the schedule slips, work is dropped in this order: optional
        extensions; experiments X4--X6; live Mode B (Mode A is kept); extra
        random seeds.
  \item Never dropped: baselines B1--B3, the proposed model P, the per-noise-level
        evaluation and ablations X1--X3.
\end{itemize}
