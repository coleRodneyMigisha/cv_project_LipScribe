\section{Summary}
The project set-up is complete and implementation has started. We have created
the Trello board that tracks the Work Breakdown Structure (WBS), created the
project repository, downloaded the dataset and secured a GPU for training. As
of Monday 19~October 2026 the team is implementing the system according to the
WBS, starting with Week~1 (\emph{Setup \& Data}), which ends with Milestone~M1
on Sunday 25~October.

\section{Work completed}

\begin{description}[style=nextline,leftmargin=0pt,itemsep=4pt]
  \item[Trello board]
    The board turns the WBS into cards: one list per week, plus
    \emph{In Progress}, \emph{In Review} and \emph{Done}. Each card has an
    owner, a reviewer, a due date and a checklist, and each week ends with a
    milestone card (M1--M9). Reference cards hold the team roles, the working
    agreement and the order in which work is dropped if the schedule slips.
  \item[Code repository]
    The GitHub repository
    (\url{https://github.com/coleRodneyMigisha/cv_project_LipScribe}) has been
    created for all code and documentation. All code is merged through pull
    requests that the card's reviewer must approve.
  \item[Dataset]
    The GRID audio-visual corpus has been downloaded. The data is stored
    outside Git and is not modified; integrity checks and the
    speaker-independent train/validation/test split follow this week.
  \item[GPU for training]
    A GPU has been secured for training the models, which removes the main risk
    identified in the implementation plan.
\end{description}

\section{Next steps}
\begin{enumerate}
  \item Build the pinned environment and confirm it on every member's machine
        and on the GPU machine.
  \item Run the integrity checks on the downloaded data and fix the
        speaker-independent split (4 test speakers, 3 validation, the rest for
        training).
  \item Build the tokeniser, the noise pools and the mouth-cropping prototype.
  \item Hold the M1 review on Sunday 25~October and plan Week~2
        (preprocessing; the audio-only baseline starts training).
\end{enumerate}

\section{Risks and issues}
No blocking issues so far. With the GPU secured, the main open risk is
software compatibility (MediaPipe supports only some Python versions), which
the environment check this week addresses. The schedule and completion
criteria for all milestones are in the accompanying \emph{Project Milestones}
document.
