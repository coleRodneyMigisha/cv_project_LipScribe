# W3-02 Technical Report: Evaluation Pipeline (`evaluate.py`)

## 1. Overview and Objectives
Task **W3-02** establishes the standardized, reproducible evaluation engine for all LipScribe speech recognition baselines and fusion models (B1 audio-only, B2 visual-only, B3 concatenation, and P cross-attention gated fusion).

The evaluation script adheres strictly to the project specification in Section 9 of the implementation document:
1. Loads trained model weights and configuration from a saved checkpoint (`best.pt`).
2. Evaluates held-out test speakers across five standardized acoustic conditions ($\text{clean}, 10\text{ dB}, 5\text{ dB}, 0\text{ dB}, -5\text{ dB}$).
3. Calculates corpus-level Word Error Rate (WER) and Character Error Rate (CER) per SNR, per individual speaker, and aggregate.
4. Generates publication-ready error curves vs. SNR (`test_snr_curves.png`) and training curves (`training_curves.png`).
5. Logs per-utterance references, hypotheses, error rates, and fusion gate values to `hypotheses.csv` for fine-grained error analysis.
6. Provides modality ablation flags (`--drop-modality {audio, visual}`) for test-time robustness assessment.
7. Safely updates `experiments/results.csv` with official test performance.

---

## 2. Implementation Architecture

### A. Modular Scoring Engine (`score_checkpoint`)
- **Deterministic Pre-mixed Test Sets:** Evaluates on fixed noisy audio test sets generated by `make_noisy_test.py` under `data/processed/noisy_test/`, guaranteeing exact cross-model reproducibility.
- **Config-Driven Decoding:** Automatically selects the decoding policy configured in `config.yaml` (greedy CTC decoding or CTC prefix beam search).
- **Fusion Gate Extraction:** Extracts the per-frame gated attention weight $g_t \in [0, 1]$ if present, averaging it over valid utterance frames to measure acoustic vs. visual reliance across noise levels.
- **Modality Ablation Support:** Allows dropping audio features or video frames at evaluation time to evaluate modality drop-off behavior.

### B. Output Artifacts
For each evaluation run, the script writes a self-contained bundle under `reports/<run_name>/`:
- `test_metrics.csv`: Aggregate and per-speaker WER/CER breakdowns across all SNRs.
- `hypotheses.csv`: Utterance-by-utterance references, predictions, WER, CER, and fusion gate scalar.
- `test_snr_curves.png`: Dual-panel plot of Test WER vs SNR and Test CER vs SNR.
- `training_curves.png`: Training/validation loss and validation error rates reconstructed from TensorBoard logs.
- `evaluation_report.md`: Structured markdown table reporting official test results.
